推上 GitHub（Git Bash）
========================

開 Git Bash（開始功能表搜尋 "Git Bash"），整塊貼進去，按 Enter。

    cd /c/Users/david/Downloads/tw-cb-data
    git init
    git branch -M main
    git add .
    git commit -m "櫃買 CB 端點與抓取器（端點經本機實地驗證）"
    git remote add origin https://github.com/david26984741-cell/tw-cb-data.git
    git push -u origin main


會遇到的兩種狀況
----------------

1) 跳出瀏覽器要你授權 GitHub
   照做即可。你已經在用 GitHub Desktop，憑證通常已經存著，多半不會問。

2) 出現 "remote origin already exists"
   把 remote add 那行換成：

    git remote set-url origin https://github.com/david26984741-cell/tw-cb-data.git

   然後只重跑最後一行 git push -u origin main


確認成功
--------
    https://github.com/david26984741-cell/tw-cb-data

應該看得到 README.md、scripts/、requirements.txt。
